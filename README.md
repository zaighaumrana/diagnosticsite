# Real Diagnostic Center Website

Static awareness website for Real Diagnostic Center, covering laboratory services, health packages, test information, and pharmacy services.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root. Keep `index.html` at the top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. GitHub will show the public website address after deployment finishes.

## Preview locally

You can open `index.html` directly in a browser. No installation or build command is required.

## Important content note

Before making the website public, replace any placeholder contact details, opening hours, prices, and medical information with details confirmed by Real Diagnostic Center.

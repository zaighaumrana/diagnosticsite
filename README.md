# Real Diagnostic Center Website

A responsive four-page awareness website for Real Diagnostic Center, Real Lab Lahore, and Real Pharmacy Lahore.

## Pages

- `index.html` — Real Diagnostic Center home page
- `laboratory.html` — laboratory services, test departments, health profiles, and preparation guidance
- `pharmacy.html` — pharmacy support, medicine-safety guidance, and product categories
- `about.html` — center overview, values, address, and contact details

## Publish with GitHub Pages

1. Create or open a GitHub repository.
2. Upload everything in this folder to the repository root. Keep `index.html` at the top level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

No installation or build command is required.
